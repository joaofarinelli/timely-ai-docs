## Etapa 1 — Criar uma Tabela

No menu lateral, acesse **Tabelas**. A tela exibe todas as tabelas do workspace.

1. Clique em **+ Adicionar tabela**.
2. Informe um **Nome** com até 50 caracteres.
3. Se quiser, adicione uma **Descrição** de até 250 caracteres. O agente usa esse texto para entender a finalidade da tabela.
4. Clique em **Criar tabela**.

Use nomes que deixem o objetivo claro, como `Catálogo de produtos`, `Leads do WhatsApp` ou `Agenda de outubro`.

## Etapa 2 — Adicionar colunas

Com a tabela aberta, clique em **+ Adicionar coluna** e preencha:

| Campo | Descrição | Requisitos |
|-------|-----------|------------|
| **Nome** | Identifica o campo para usuários e agentes. | Até 50 caracteres. |
| **Descrição** | Explica quando e como o campo deve ser preenchido. | De 3 a 250 caracteres. |
| **Tipo** | Define quais valores a coluna aceita. | Não pode ser alterado depois da criação. |
| **Busca semântica** | Permite pesquisar por significado. | Opcional e disponível somente para `Texto`. |
| **Campo obrigatório** | Exige que o agente colete um valor antes de inserir o registro. | Opcional. |

<Note>
  O tipo da coluna é permanente. Se precisar trocar o tipo mais tarde, crie uma nova coluna e migre os dados.
</Note>

## Tipos de coluna disponíveis

| Tipo | Descrição | Exemplos |
|------|-----------|----------|
| `Texto` | Texto livre. Pode usar busca semântica. | nome, descrição, observação, URL |
| `Número` | Valor inteiro ou decimal. | preço, quantidade, nota, capacidade |
| `Booleano` | Valor verdadeiro ou falso. | disponível, ativo, aprovado |
| `Arquivo` | Arquivo anexado ao registro. | contrato, imagem, comprovante |
| `Seleção` | Uma opção escolhida de uma lista predefinida. Cada opção tem nome, cor e posição. | estágio, status, prioridade, categoria |

### Configurar uma coluna de Seleção

Ao escolher o tipo **Seleção**:

1. Dê um nome para cada opção.
2. Escolha a cor que identifica a opção.
3. Use as setas para definir a ordem.
4. Clique em **Adicionar opção** para incluir novos valores.

Uma coluna de Seleção deve ter pelo menos uma opção e aceita até 50. Os nomes devem ser únicos e podem ter até 50 caracteres.

As opções também podem representar as colunas de uma [visualização Kanban](/guides/tables/kanban). Por exemplo, as opções `Novo`, `Em andamento` e `Concluído` formam um fluxo de três estágios.

<Warning>
  Ao excluir uma opção, os registros que usavam esse valor passam para **Sem valor**. Revise esses registros e atribua um novo valor quando necessário.
</Warning>

## Etapa 3 — Adicionar e editar registros

Depois de definir as colunas, preencha a tabela de uma destas formas:

- **Entrada manual**: clique em **+ Adicionar linha** e edite as células diretamente na grade.
- **Importação XLSX**: clique em **Importar**, envie uma planilha `.xlsx`, associe as colunas e revise os dados antes de concluir.
- **Agente**: conecte ferramentas de Datagrid para que o agente insira ou atualize registros durante as conversas.

Em uma célula de Seleção, escolha uma das opções configuradas ou use **Limpar** para deixar o campo sem valor. Na importação XLSX, use no arquivo o nome exato de uma opção existente; diferenças entre maiúsculas e minúsculas são aceitas.

## Etapa 4 — Atualizar ou excluir a Tabela

Você pode editar o nome e a descrição da tabela, adicionar colunas e ajustar as opções de colunas de Seleção a qualquer momento.

Para excluir uma tabela:

1. Na lista de tabelas, abra o menu de opções.
2. Selecione **Excluir tabela**.
3. Confirme a exclusão.

<Warning>
  A exclusão é permanente. Todas as linhas e colunas são apagadas, e os agentes conectados perdem o acesso imediatamente.
</Warning>
