---
title: "Effort"
---

**Effort** defines how much computational reasoning an Agent invests before producing an answer. <br />
It can be interpreted as the number of internal reasoning “steps” performed per message.

- **Low Effort**: fast, lightweight responses
- **Medium Effort**: moderate contextual analysis
- **High Effort**: deeper reasoning, multi-step orchestration, and better handling of complex logic

<Note>
The higher the Effort, the more credit or API cost may be consumed, since additional iterations are executed internally.
</Note>
