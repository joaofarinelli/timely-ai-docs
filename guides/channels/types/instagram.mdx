---
title: "Instagram"
---

The **Instagram** channel follows the same authentication pattern as WhatsApp Official, but directly through Instagram’s own OAuth page.

### Connection Flow

1. Select **Type: Instagram**.
2. Set the name, description, and responder.
3. Click **Create Connection**.
4. You will be redirected to Instagram’s login page.
5. Log in using the Instagram account that your Agent should use for client communication.
6. Authorize the connection.

After completing authentication, the Agent will be able to send and receive messages directly from that Instagram account within Timely.ai.
