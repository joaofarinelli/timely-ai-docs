description: "Learn how to create a Table (Datagrid), configure typed columns — including Select — and add records."

## Step 1 — Create a Table

In the sidebar, go to **Tables**. The screen displays every table in the workspace.

1. Click **+ Add table**.
2. Enter a **Name** of up to 50 characters.
3. Optionally, add a **Description** of up to 250 characters. The agent uses it to understand the table's purpose.
4. Click **Create table**.

Use names that make the purpose clear, such as `Product catalog`, `WhatsApp leads`, or `October schedule`.

## Step 2 — Add Columns

With the table open, click **+ Add column** and fill in:

| Field | Description | Requirements |
|-------|-------------|--------------|
| **Name** | Identifies the field for users and agents. | Up to 50 characters. |
| **Description** | Explains when and how the field should be filled in. | 3 to 250 characters. |
| **Type** | Defines which values the column accepts. | Cannot be changed after creation. |
| **Semantic search** | Enables meaning-based search. | Optional and available only for `String`. |
| **Required field** | Requires the agent to collect a value before inserting the record. | Optional. |

<Note>
  The column type is permanent. If you need a different type later, create a new column and migrate the data.
</Note>

## Available Column Types

| Type | Description | Examples |
|------|-------------|----------|
| `String` | Free text. Supports semantic search. | name, description, notes, URL |
| `Number` | Integer or decimal value. | price, quantity, score, capacity |
| `Boolean` | True or false value. | available, active, approved |
| `File` | A file attached to the record. | contract, image, receipt |
| `Select` | One option chosen from a predefined list. Each option has a label, color, and position. | stage, status, priority, category |

### Configure a Select Column

After choosing **Select** as the type:

1. Enter a label for each option.
2. Choose the color that identifies the option.
3. Use the arrows to set the order.
4. Click **Add option** to include more values.

A Select column must have at least one option and supports up to 50. Labels must be unique and can contain up to 50 characters.

The options can also become the columns of a [Kanban view](/en/guides/tables/kanban). For example, `New`, `In progress`, and `Done` form a three-stage workflow.

<Warning>
  When you delete an option, records using it move to **No value**. Review those records and assign a new value when needed.
</Warning>

## Step 3 — Add and Edit Records

After defining the columns, populate the table in one of these ways:

- **Manual entry**: click **+ Add row** and edit cells directly in the grid.
- **XLSX import**: click **Import**, upload an `.xlsx` workbook, map the columns, and review the data before completing the import.
- **Agent**: connect Datagrid tools so an agent can insert or update records during conversations.

In a Select cell, choose one of the configured options or use **Clear** to leave it empty. For XLSX imports, use the label of an existing option in the workbook; matching is case-insensitive.

## Step 4 — Update or Delete the Table

You can edit the table name and description, add columns, and adjust Select options at any time.

To delete a table:

1. Open the options menu in the table list.
2. Select **Delete table**.
3. Confirm the deletion.

<Warning>
  Deletion is permanent. All rows and columns are erased, and connected agents lose access immediately.
</Warning>
